## 一、i18n 多語系支援

### 目標
公開問卷頁面與後台管理介面均支援多語切換，讓國際用戶也能使用。

### 優先語系
| 優先順序 | 語系 | 代碼 |
|---------|------|------|
| 1 | 繁體中文 | zh-TW |
| 2 | 英文 | en |
| 3 | 日文 | ja |

### 實作範圍
- **公開問卷頁**：UI 文案（按鈕、提示、完成頁）多語系
- **後台管理介面**：導航、表單 label、系統提示多語系
- **問卷題目本身**：支援多語欄位（每題可設定不同語系的 content / options）
- **SEO**：`hreflang` 標籤、多語 OG metadata

### 技術選型
- 使用 `next-intl` 或 Next.js 內建 i18n routing
- 語系檔案放置 `src/messages/{locale}.json`
- URL 結構：`/{locale}/{org}/{slug}` 或 subdomain

## 二、n8n 自動化通知整合

### 目標
讓租戶管理員不需寫程式，就能透過 n8n 設定自動化通知流程。

### 核心場景

#### 即時通知
| 觸發條件 | 通知管道 | 說明 |
|---------|---------|------|
| 問卷提交 | Email / LINE / Slack | 新回覆即時推播給管理員 |
| CRM 標籤變動 | LINE | 用戶標籤更新通知 |
| 問卷回覆達門檻 | Email | 例如達 100 筆自動通知 |

#### 定時報告
| 頻率 | 內容 | 通知管道 |
|------|------|---------|
| 每日 | 新回覆數、熱門選項、完成率 | Email |
| 每週 | 週報摘要 + CRM 標籤統計 | Email / LINE |
| 即時 | 異常監控（回覆數異常下降） | LINE / Slack |

#### 自動化工作流
| 場景 | 流程 |
|------|------|
| 問卷提交 → Webhook → n8n → 多重通知 | Email + LINE + Slack 同時推送 |
| 回覆數達門檻 → 自動關閉問卷 | n8n 監聽 + API 呼叫 |
| 自動匯出至 Google Sheets / Notion | 定時或即時同步 |
| AI 分析摘要 → 自動寄信 | n8n + OpenAI → Email |
| 串接第三方 CRM | HubSpot / Salesforce 雙向同步 |

### 技術架構
```
[ 問卷系統 ] → Webhook POST → [ n8n ] → [ Email / LINE / Slack / Sheets / CRM ]
                                  ↑
                            排程觸發 (Cron)
```

### 實作步驟
1. 系統內建 Webhook 發送機制（問卷提交、標籤變動等事件）
2. 後台新增「自動化」設定頁，讓管理員填入 n8n Webhook URL
3. 提供 n8n 範本模板（一鍵匯入）
4. 進階：內嵌 n8n 編輯器（iframe 或 API 整合）

## 三、產品包裝與商業化

### Landing Page
- 功能展示（9 種主題、AI 出題、分流邏輯、CRM 標籤）
- 客戶案例 / 使用場景
- 互動 Demo（直接試填範例問卷）
- 定價方案比較表

### 定價方案

| 方案 | 價格 | 問卷數 | 回覆/月 | 管理員 | 特色功能 |
|------|------|--------|---------|--------|---------|
| **Free** | NT$0 | 1 | 100 | 1 | 基礎分析 |
| **Pro** | NT$490/月 | 無限 | 5,000 | 5 | LINE 整合、AI 出題、A/B 測試、完整分析 |
| **Enterprise** | 聯繫我們 | 無限 | 無限 | 無限 | 白標、API、自訂網域、專屬支援 |

### 註冊 Onboarding 流程
1. Email / Google 註冊
2. 建立組織（填寫組織名、slug）
3. 選擇方案（Free 直接開始）
4. 引導建立第一份問卷（3 步驟嚮導）
5. 預覽 + 發布

### API 文件
- RESTful API（問卷 CRUD、回覆查詢、CRM 標籤）
- API Key 認證
- Rate Limiting
- Webhook 事件文件
- OpenAPI / Swagger 文件自動產生

### 白標支援（Enterprise）
- 自訂 Logo / 品牌色
- 自訂網域（CNAME）
- 移除 "Powered by SnowRealm" 字樣
- 自訂 Email 發送地址
