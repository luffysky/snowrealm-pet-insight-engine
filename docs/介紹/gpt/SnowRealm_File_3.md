# SnowRealm Insight Engine --- 爆款問卷模板庫（10套）

## 模板1：你在朋友眼中是什麼人？

Prompt： 你是問卷設計師，設計一份「朋友眼中人格測驗」，10題，輕鬆有趣。

## 模板2：你的戀愛人格

Prompt： 設計戀愛心理測驗，帶情緒共鳴，避免冒犯。

## 模板3：你是哪種動物？

Prompt： 設計娛樂型人格問卷，結果需具象角色。

## 模板4：朋友對你的真實印象

Prompt： 設計匿名回饋問卷，語氣委婉。

## 模板5：你的未來人生路線

Prompt： 設計預測型問卷，結果帶故事性。

## 模板6：你在職場的角色

Prompt： 設計職場人格問卷，偏專業但有趣。

## 模板7：情侶默契測驗

Prompt： 設計雙人互動問卷，避免衝突。

## 模板8：你的人生價值觀

Prompt： 設計價值觀測驗，偏深度。

## 模板9：你的隱藏天賦

Prompt： 設計探索型問卷，帶驚喜感。

## 模板10：朋友適合你的程度

Prompt： 設計關係測驗，語氣正向包裝。
