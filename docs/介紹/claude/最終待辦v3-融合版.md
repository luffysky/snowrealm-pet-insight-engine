## 戰略定位更新

V5 的核心洞察是對的：**Insight Engine 不只是 B 端問卷工具，更是 C 端人格洞察平台。**

```
雙引擎並行：
  B 端（已完成 90%）：問卷 → AI 洞察 → LINE 推播 → 營收
  C 端（待建設）：測驗 → 認知落差 → 解鎖 → 故事 → 分享 → 裂變

主引擎：認知落差引擎（你以為 vs 別人眼中）
副引擎：AI 故事敘事
輔助引擎：Z 幣 / 裂變 / 廣告

為什麼認知落差是主引擎：
  一般心理測驗：「你是什麼動物」→ 看完就忘
  認知落差：「你以為自己很主動，但別人覺得你很有距離」→ 停下來、有感、想分享、願意付費
```

## Phase 2：認知落差引擎（V5 核心 P0）★ 最重要的新功能

這是讓人願意付費的核心。不是「你是什麼動物」，而是「你以為你很主動，但朋友覺得你有距離感」。

### 2a. 認知落差計算引擎

```
📄 src/lib/cognitiveGapEngine.ts

核心函式：
  calculateGap(selfScore, othersAvg) → gap_score
  
  confidence_weight = min(1, log(response_count + 1) / 3)
  weighted_gap = (selfScore - othersAvg) * confidence_weight

  Gap 分級：
    0-10  → 幾乎一致
    11-25 → 輕微落差
    26-45 → 明顯落差
    46+   → 強烈落差

  generateGapSnapshot(userId, surveyId) → 計算所有 trait 的落差快照
  generateGapReport(userId, surveyId, style) → AI 生成認知落差報告
```

### 2b. 認知落差 API

```
📄 src/app/api/cognitive-gap/calculate/route.ts
   POST — 計算落差（填答完成後自動呼叫）

📄 src/app/api/cognitive-gap/report/route.ts
   GET — 取得落差報告
   POST — 生成新報告（帶 style 參數）

📄 src/app/api/cognitive-gap/snapshot/route.ts
   GET — 取得落差快照（雷達圖用）
```

### 2c. 認知落差結果頁

```
📄 src/app/(public)/gap-result/[userId]/page.tsx

結構（V5 定義）：
  卡片 1：總結 — 最一致特質 + 最大落差特質 + 一句話
  卡片 2：雷達圖 — 自評 vs 他評（3-6 個 trait）
  卡片 3：最大落差分析 — 你以為/別人覺得/原因/影響
  卡片 4：改善建議 — 3 件立刻能做的事 + 下一份問卷 CTA

免費版只顯示卡片 1，其餘鎖住。
```

### 2d. AI Prompt（V5 定義的誠實但不傷人版）

```
📄 src/lib/gapPrompts.ts

5 種風格：
  A：溫柔療癒型（免費版）
  B：刺痛覺醒型（付費前鎖點，最高轉換率）
  C：小說劇場型（Story Card 用）
  D：商業洞察型（B 端用）
  E：顧問行動型（最高價值）
```
