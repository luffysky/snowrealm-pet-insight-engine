# SnowRealm Insight Engine — 商業模式與商業閉環分析

---

## 一、商業模式總覽

Insight Engine 的商業模式是 **SaaS 訂閱制 + 用量計費**，核心邏輯是：

> 讓中小企業「免費上癮 → 數據累積 → 付費解鎖 → 離不開」

這不是賣工具，是賣「持續產出洞察的能力」。工具可以被替換，但數據和洞察不行。

---

## 二、收入來源

### 主要收入：SaaS 訂閱

| 方案 | 月費 | 目標客群 | 客戶終身價值（LTV） |
|------|------|---------|-------------------|
| Free | NT$0 | 試水溫的人 | NT$0（但提供口碑和數據） |
| Pro | NT$490 | 有 LINE 經營需求的小店 | NT$490 × 18 個月 = NT$8,820 |
| Business | NT$1,290 | 連鎖/品牌/機構 | NT$1,290 × 24 個月 = NT$30,960 |
| Enterprise | 客製 | 大型企業 | NT$5,000+ × 36 個月 = NT$180,000+ |

### 潛在收入（Phase 2）

- **模板市集抽成**：使用者上架付費模板，平台抽 30%
- **AI 加值包**：超過免費額度的 AI 分析按次計費
- **白標服務**：幫品牌客製自己的問卷平台（Logo/網域/主題）
- **數據報告代製**：幫不想自己操作的客戶代為分析出報告

## 三、商業閉環設計

這是整個系統最核心的設計——**每一個環節都把使用者推向下一個環節**，形成一個自我強化的循環。

### 閉環 1：問卷 → 數據 → 洞察 → 行動 → 問卷

```
        ┌──────────────────────────────────────────┐
        │                                          │
        ▼                                          │
   【建立問卷】                                    │
   AI 出題 / 選模板                                │
        │                                          │
        ▼                                          │
   【收集回覆】                                    │
   LINE / 網頁 / QR                                │
        │                                          │
        ▼                                          │
   【AI 分析】                                     │
   洞察報告 + 商業建議                              │
        │                                          │
        ▼                                          │
   【採取行動】                                    │
   LINE 分眾推播 / 調整策略                         │
        │                                          │
        ▼                                          │
   【追蹤效果】───────────────────────────────────┘
   建立追蹤問卷，驗證改善是否有效
```

**關鍵**：每次行動後都需要一份新問卷來驗證效果，所以使用者會持續使用。

### 閉環 2：CRM 標籤飛輪

```
   填完問卷 → 自動貼標籤 → LINE 分眾推播 → 推播帶來更多填答 → 更多標籤
       ▲                                                          │
       └──────────────────────────────────────────────────────────┘
```

每一次填答都讓 CRM 更精準，推播更精準，帶來更多填答。這個飛輪一旦轉起來，客戶不可能停用，因為所有的客戶分群數據都在平台上。

### 閉環 3：Story × Data 傳播飛輪

```
   填完問卷 → 生成故事卡片 → 分享到 LINE / IG → 朋友看到 → 也來填 → 更多卡片
       ▲                                                           │
       └───────────────────────────────────────────────────────────┘
```

每個填答者都是潛在的傳播節點。故事卡片上有「填寫問卷，留下你的故事 →」的 CTA，直接帶新流量。這是零成本的病毒式行銷。

### 閉環 4：免費試用 → 付費轉換

```
   註冊 → 30 天全功能免費 → 數據累積 → 到期降級 → AI 鎖住但數據在
                                                        │
                                                        ▼
                                                  「我要繼續看報告」
                                                        │
                                                        ▼
                                                     升級付費
```

**降級不刪數據**是關鍵。使用者的問卷、回覆、標籤、洞察報告都還在，只是 AI 功能鎖住了。他們看得到但用不了，這比什麼行銷文案都有效。

## 四、獲客策略

### Phase 1：手動推（前 50 個客戶）

**不花錢，用時間換。**

1. **主動幫客戶建問卷**：找 10-20 家有 LINE 官方帳號的中小企業（寵物店、咖啡廳、美甲美髮、健身房），直接跟他們說「免費幫你做一份顧客調查 + AI 分析報告」。
2. **用模板降低門檻**：16 個行業模板讓他們不用想，選一個就開始。
3. **幫他們發問卷**：設定好 LINE 推播，讓他們的顧客在 LINE 裡直接填。
4. **展示 AI 報告**：一週後把 AI 洞察報告拿給老闆看，「你的顧客 72% 覺得等太久，建議你調整出餐流程」。

**轉換點**：當老闆看到「原來我的顧客是這樣想的」，他會問你「這個多少錢」。

### Phase 2：內容行銷（50-500 個客戶）

1. **案例分享**：把 Phase 1 的成功案例寫成文章/短影片。「某寵物店用我們的問卷發現 80% 的客人想要寵物美容服務 → 新增美容服務 → 營收成長 30%」。
2. **IG / FB 社群**：分享有趣的問卷數據和故事卡片。
3. **LINE 官方帳號**：用我們自己的平台經營，吃自己的狗糧。
4. **SEO**：問卷模板頁面 + 行業問卷教學文章。

### Phase 3：自動化增長（500+ 客戶）

1. **故事卡片病毒傳播**：每個填答者分享卡片 → 朋友看到 → 新流量。
2. **模板市集**：使用者上架模板 → 其他人使用 → 平台活躍度上升。
3. **API 串接**：其他 SaaS 串接我們的問卷功能，帶來 B2B 客戶。
4. **白標服務**：大客戶要自己的品牌問卷平台 → 客製化收費。

## 五、留存策略

### 為什麼客戶不會離開

1. **數據鎖定**：所有問卷、回覆、標籤、AI 報告都在平台上。搬走成本極高。
2. **LINE 綁定**：LINE 推播規則、Rich Menu、標籤分群全都設定好了。換平台等於全部重來。
3. **AI 報告累積**：每個月的洞察報告形成趨勢比較。「上個月 NPS 是 42，這個月掉到 38，原因是...」這種縱向比較只有持續使用才有。
4. **習慣養成**：每週收到 AI 週報 → 看數據 → 做決策。一旦養成習慣，停用就像少了一雙眼睛。

### 流失預警

| 信號 | 意義 | 自動行動 |
|------|------|---------|
| 7 天未登入 | 冷卻中 | LINE 推送：「上週新增 12 筆回覆，AI 發現了新趨勢」 |
| 14 天未建新問卷 | 可能找不到場景 | 推送行業模板：「試試我們新的餐飲滿意度模板？」 |
| 問卷 0 回覆超過 7 天 | 不知道怎麼推廣 | 推送教學：「3 招讓你的問卷回覆率翻倍」 |
| 試用即將到期 | 轉換關鍵期 | 推送 AI 報告預覽：「你的數據已準備好，升級即可查看完整報告」 |

## 六、單位經濟

### 假設

- Pro 月費 NT$490
- 平均客戶留存 18 個月
- 月 churn rate 約 5.5%
- CAC（獲客成本）Phase 1 幾乎為零（手動推）

### 計算

```
LTV = NT$490 × 18 = NT$8,820
CAC = NT$0（Phase 1 手動）~ NT$500（Phase 2 內容行銷）
LTV/CAC = 8,820 / 500 = 17.6x（健康值 > 3x）

毛利率：
  月費收入：NT$490
  AI 成本（GPT-4o-mini）：約 NT$5-10 / 客戶 / 月
  伺服器（Zeabur + Supabase）：約 NT$20 / 客戶 / 月
  毛利：NT$460 → 毛利率 93.8%

損益平衡：
  固定成本（開發 + 伺服器基礎費）：約 NT$5,000 / 月
  需要 11 個 Pro 客戶 即可損益平衡
```

### 營收目標

| 時間 | Pro 客戶數 | 月營收 | 里程碑 |
|------|-----------|--------|--------|
| Month 1 | 0（免費試用） | NT$0 | 找到 10 個試用客戶 |
| Month 2 | 5 | NT$2,450 | 開始收費 |
| Month 3 | 10 | NT$4,900 | 接近損益平衡 |
| Month 6 | 30 | NT$14,700 | 穩定正現金流 |
| Month 12 | 100 | NT$49,000 | 考慮 Business 方案客戶 |
| Month 24 | 300 | NT$147,000+ | 加入 Enterprise 客戶 |

## 七、風險與應對

| 風險 | 機率 | 影響 | 應對 |
|------|------|------|------|
| 大廠抄襲（SurveyCake 加 AI） | 中 | 高 | 靠 LINE 閉環 + Story 差異化，他們做不了 |
| 用戶不願付費 | 中 | 高 | 調低 Pro 價格到 NT$290，或加強免費版限制 |
| AI 成本上升 | 低 | 中 | 已用 GPT-4o-mini + 模板快取，成本極低 |
| LINE API 改版 | 低 | 中 | 抽象層已做好（lineConfig.ts），改接口不改邏輯 |
| 找不到營運夥伴 | 中 | 高 | 自己先做 10 個客戶驗證，證明模式可行再找人 |

## 八、終極願景

```
Year 1：台灣中小企業的 AI 問卷工具
Year 2：東南亞（越南、泰國）的 LINE/WhatsApp 問卷平台
Year 3：SnowRealm 生態系的數據中樞 — 所有生態產品的洞察都從這裡產出
```

Insight Engine 不是終點。它是 SnowRealm 生態系的「神經系統」——負責收集和分析所有來自使用者的數據。毛行天下用它了解飼主，彩虹國用它了解失去寵物的人，未來的 FlowLightAI 用它了解生產力工具的使用者。

**一套引擎，服務整個生態系。**
