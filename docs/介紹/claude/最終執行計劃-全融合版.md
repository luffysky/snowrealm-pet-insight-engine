## Phase 2：認知落差引擎 ★ 最核心新功能

V4/V5 定義的主引擎：**你以為 vs 別人眼中**

### 2a. 計算引擎
```
📄 src/lib/cognitiveGapEngine.ts
   calculateGap(selfScore, othersAvg) → gap_score
   confidence_weight = min(1, log(response_count + 1) / 3)
   weighted_gap = gap * confidence_weight
   Gap 分級：0-10 一致 / 11-25 輕微 / 26-45 明顯 / 46+ 強烈
   generateGapSnapshot(userId, surveyId)
   generateGapReport(userId, surveyId, style)
```
