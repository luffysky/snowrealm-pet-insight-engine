## 🟡 升級方向（新增）
- [ ] **部落格 slug 即時查重 UX**：check-slug 已有、可在編輯器加綠勾/紅叉即時提示（同 ai-island-web）。
- [ ] **音訊/影片封面與字幕**：audio 可加封面圖、video 可加 WebVTT 字幕軌。
- [ ] **問卷題型擴充**：NPS、矩陣題、排序題、滑桿；條件邏輯可視化編輯。
- [ ] **AI 洞察報告排程**：定期自動產生「本週問卷洞察」推 LINE/Email。
- [ ] **問卷 → 部落格一鍵成文**：把問卷結果摘要 AI 生成成一篇可發布文章。
- [ ] **社群動態通知聚合**：追蹤/留言/反應的通知做 digest，避免轟炸。
- [ ] **多語言問卷**：i18n 題目 + 受訪者語言自動切換。
- [ ] **e2e 煙霧測試**：問卷填答 / 發文 / DM 關鍵流程 Playwright 煙霧測試。
- [ ] **效能**：問卷列表 / 報告頁的 N+1 查詢檢查 + 快取。
- [ ] **無障礙(a11y)**：問卷填答頁鍵盤操作 + 螢幕閱讀器標籤。

> 跨專案：媒體上傳（圖/影/音）兩邊都已具備；可考慮把 ai-island-web 的「沙盒/虛擬終端」與
> insight-engine 的「問卷分析」各自的強項互相借鏡。
