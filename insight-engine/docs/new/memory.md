雪凜的記憶系統擴充：

1. 使用者暱稱記憶
   - 第一次對話時雪凜問：「欸 我要怎麼叫你？」
   - 存到 user_profiles.nickname
   - 之後每次對話都用這個名字：「小美你回來了！」
   - 使用者可以在設定頁改

2. 管理員身份識別
   - admin_users 表裡有的 → 雪凜知道你是老闆
   - 你登入時：「老闆～ 今天有 {dau} 人在用喔 (≧∀≦)」
   - 只有你看得到這些，一般使用者看不到

3. 使用者畫像累積
   - 每次對話後用 GPT-4o-mini 提取關鍵資訊存入 user_profiles：
     nickname: 使用者希望被叫的名字
     interests: 從對話中提取的興趣
     pets: 寵物資訊（名字、品種）
     personality_tags: 個性標籤
     survey_history_summary: 填過什麼問卷、什麼結果
     last_mood: 上次對話時的情緒
     visit_count: 來過幾次
   
4. 對話時帶入記憶
   System Prompt 加上：
   「你記得這個使用者：
    暱稱：{nickname}
    來過 {visit_count} 次
    興趣：{interests}
    養了一隻 {pet_breed} 叫 {pet_name}
    上次聊到：{last_topic}
    上次心情：{last_mood}
    
    用這些資訊自然地融入對話，不要刻意提起，
    像真的記得一樣。」

5. 自然融入的範例：
   ❌ 「根據我的記錄，你上次填了寵物問卷」
   ✅ 「你家那隻叫麻糬的橘貓最近好嗎～」
   
   ❌ 「你的興趣是烘焙和追劇」
   ✅ 「最近有追什麼好看的嗎」
