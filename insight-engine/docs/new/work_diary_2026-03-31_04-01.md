#### 🔴→✅ BUG-GUIDE-1 雪凜/凜空 Boss 模式未啟動

**問題**：即使 DB 有 `platform_unlimited=true` 且 `role=super_admin`，雪凜仍以一般模式問候，老闆 slash 指令不可用。

**根因分析**：
1. `/api/guide/turns` 的 `isOwner = await isUserPlatformUnlimited(userId)` — 只判斷 DB
2. 若 `platform_unlimited` 欄位不存在或查詢失敗，`isOwner = false`
3. 前端的 `turnsInfo.isOwner` 來自 turns API，驅動 boss greeting 和 slash 指令
4. 即使 `guide/chat` 內部有 `|| super_admin` fallback，前端仍認為不是老闆

**修復**：
```
src/app/api/guide/turns/route.ts
  — const isOwner = isUnlimited || payload?.role === 'super_admin'
  — if (isUnlimited || payload?.role === 'super_admin') { return ... }

src/app/api/guide/chat/route.ts
  — const isUnlimited = await isUserPlatformUnlimited(userId) || userRole === 'super_admin'
```

**驗證**：super_admin 登入後，雪凜問候「嗨嗨，老闆！歡迎回來 ✨」，`/全平台` 等 owner 指令可用。

#### 🔴→✅ BUG-BLOG-1 密碼保護文章輸入密碼後進不去

**問題**：密碼正確、unlock API 設定 cookie 成功，但頁面重新載入後仍顯示密碼輸入頁。

**根因分析**：
- `page.tsx` 是 Next.js Server Component，`getArticle()` 用 `fetch()` 呼叫內部 API
- Server Component 的 `fetch()` 不會自動帶入瀏覽器 cookies
- `/api/blogs/[slug]/route.ts` 第 97 行：`req.cookies.get('article_unlock_${article.id}')` 讀到的 Request 是來自 SSR fetch，沒有 cookie
- 結果：`unlockCookie !== '1'` → 繼續顯示密碼頁

**修復**：
```
src/app/blogs/[userSlug]/[articleSlug]/page.tsx
  — import { cookies } from 'next/headers'
  — getArticle() 中：
    const cookieStore = await cookies()
    const cookieHeader = cookieStore.getAll().map(c => `${c.name}=${c.value}`).join('; ')
    const res = await fetch(url, { cache: 'no-store', headers: { Cookie: cookieHeader } })
```

**驗證**：輸入正確密碼 → reload → 文章內容正常顯示。

#### 🔴→✅ BUG-BLOG-2 部落格淺色模式白字看不見

**問題**：`ArticleThemeToggle` 切換到淺色模式，所有文字幾乎不可見（白底白字）。

**根因分析**：
- 現有 `.blog-light` CSS 只設 `color` 在父元素，但子元素有明確的 Tailwind 類別如 `text-white/80`
- CSS specificity：子元素自己的 class（0,1,0）比從父元素繼承的 color 更優先
- 結果：所有 `text-white/*` 的元素維持白色文字

**修復**：
```
src/app/globals.css
  — 在 .blog-light section 後新增：
  .blog-light .blog-article-root .text-white { color: #1a1020 !important; }
  .blog-light .blog-article-root [class*="text-white/9"],
  .blog-light .blog-article-root [class*="text-white/8"] { color: rgba(26,16,32,0.88) !important; }
  ... （9 個白色透明度層級全部覆蓋）
  .blog-light .blog-article-root [class*="border-white"] { border-color: rgba(0,0,0,0.10) !important; }
  .blog-light .blog-article-root [class*="bg-white/"] { background-color: rgba(0,0,0,0.04) !important; }
  .blog-light .blog-article-root .bg-slate-950 { background-color: #f0ecfa !important; }
  ... 表單輸入框、按鈕、漸層等
```

### 技術學習記錄

1. **Next.js Server Component 的 fetch() 不帶 cookies**：Server Component 中發起的內部 fetch 請求不包含瀏覽器 session cookies。解法：用 `next/headers` 的 `cookies()` 讀取後手動轉發。

2. **CSS specificity 與 !important**：Tailwind 的工具類別（utility classes）比繼承的 `color` 優先。要覆蓋需要使用 attribute selector `[class*="text-white/"]` 配合 `!important`。

3. **非阻塞 async 操作**：在 API route 中用 IIFE `(async () => { ... })()` 執行次要任務（如儲存到 DB），不 `await` 它，讓主要回應可以立即返回。
