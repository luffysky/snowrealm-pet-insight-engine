## 一、招財 × Z 幣 品牌融合

### 1.1 招財的角色定位

```
雪凜 = Insight 的 AI 嚮導（面對使用者）
招財 = Z 幣的守護者 / 吉祥物（跟錢有關的都是牠）

雪凜帶你探索內心，招財幫你守護獎勵。
兩個角色各有分工，不搶戲。
```

### 1.2 招財的視覺設定

```yaml
名字: 招財 (Zaicai)
物種: 倉鼠（布丁鼠 / 金色系）
個性: 勤勞、愛囤東西（倉鼠頰囊 = 存錢）、偶爾貪吃
視覺元素:
  - 金色毛皮，肚子白色
  - 頰囊鼓鼓的（裝著 Z 幣）
  - 頭上戴一頂小小的金色皇冠（或星星帽）
  - 眼睛圓圓亮亮的
  - 尾巴短短的
出現場景:
  - Z 幣圖示（取代普通的硬幣 icon）
  - 獲得 Z 幣時的動畫（招財從頰囊吐出 Z 幣）
  - 商城頁面（招財站在商城門口）
  - Z 幣餘額旁邊（迷你招財坐在數字旁）
  - 儲值頁面（招財興奮的表情）
不出現的場景:
  - 問卷填寫流程（那是雪凜的場）
  - AI 對話（那是雪凜的場）
```

### 1.3 Z 幣圖示設計

```
目前：✦ 或普通硬幣 icon
改成：招財的臉（簡化版）+ Z 字

設計：
  - 圓形金色底
  - 中間是招財的正臉剪影（倉鼠輪廓 + 頰囊）
  - 右下角一個小 Z
  - 整體風格要跟液態玻璃 UI 統一（半透明金色光澤）
```

## 四、經濟平衡設計（防通膨）

### 4.1 每日 Z 幣產出上限

```
一個超活躍使用者的每日最大收入：
  每日登入:         +1
  連續登入加碼:     +5（第 7 天）
  完成 1 份問卷:    +3
  分享 1 份結果:    +5
  寫 3 篇故事:      +30
  被按讚:           +50（上限）
  每日任務 × 3:     +15
  ────────────────────
  理論最大:         ~109 Z幣/天

但實際上大多數使用者：
  登入 + 填 1 問卷 + 偶爾分享 ≈ 5-10 Z幣/天
```

### 4.2 平均回收週期

```
使用者平均每天賺 8 Z幣
一包表情 30 Z幣 → 約 4 天就能買
一套主題 150 Z幣 → 約 19 天
一套雪凜服裝 300 Z幣 → 約 38 天
傳說稱號 500 Z幣 → 約 63 天

原則：
- 最便宜的東西：3-5 天能買到（入門成就感）
- 中等的東西：2-3 週（持續動力）
- 最貴的東西：1-2 個月（長期目標）
```

### 4.3 Z 幣回收機制（消耗池）

```
除了購買商品之外，還需要有自然消耗：
  - AI 深度解讀：30 Z幣/次（最大消耗池）
  - 送禮手續費：10%（持續抽水）
  - 限定商品絕版（製造消費緊迫感）
  - 未來：問卷置頂（創作者消耗）

如果通膨嚴重（全平台 Z 幣總量成長太快）：
  - 推出高價限定商品吸收 Z 幣
  - 新增消耗場景
  - 減少某些管道的獎勵（但要公告）
```

### 4.4 Z 幣定價錨點

```
1 Z 幣 ≈ NT$0.03（心理定價，不代表可提現）

儲值定價：
  100 Z幣 = NT$30
  300 Z幣 = NT$79（打 88 折）
  500 Z幣 = NT$119（打 79 折）
  1000 Z幣 = NT$199（打 66 折）

這個定價讓使用者覺得：
  - 「我可以努力賺」（不強迫付費）
  - 「但直接買也不貴」（衝動消費）
  - 「大包比較划算」（量販心理）
```

## 五、Z 幣定位：為什麼不做提現 / 虛擬貨幣

### 5.1 法規風險

```
台灣金管會把「可提現的平台幣」視為：
  - 電子支付工具 → 需要電子支付機構許可證
  - 或有價證券 → 需要金管會核准
  
申請成本：數百萬 + 6-12 個月審查
你現在的階段完全不需要碰這個
```

### 5.2 營運風險

```
一旦 Z 幣可提現：
  ❌ 羊毛黨批量註冊 → 領 500 註冊禮 → 提現走人
  ❌ 互刷按讚機器人 → 每天刷滿 50 讚 → 提現
  ❌ 洗錢風險 → 法律責任落在平台
  ❌ 匯率波動 → 需要維護兌換系統
  ❌ 客訴激增 → 「我的錢去哪了」

不可提現的話：
  ✅ 羊毛黨沒動機（Z 幣拿不出去）
  ✅ 不需要 KYC 身份驗證
  ✅ 不需要防洗錢系統
  ✅ 經濟系統可以自由調整（不影響法幣）
```

### 5.3 商業邏輯

```
Z 幣不可提現 = 每一顆 Z 幣最終都在平台內消費
= 使用者的時間和金錢都留在你的生態裡
= 最健康的虛擬經濟模式

成功參考：
  - LINE Points：不可提現，但生態極大
  - Twitch Bits：只能平台內用，觀眾願意花錢買
  - Discord Nitro：封閉經濟，社群黏性極高
  - 遊戲內鑽石/寶石：所有手遊都是封閉幣
```

### 5.4 使用條款必須寫清楚

```
在 Z 幣的使用條款中明確說明：
1. Z 幣為平台內虛擬代幣，無法兌換為法定貨幣
2. Z 幣無法轉移至平台外部
3. Z 幣不具有投資價值
4. 平台保留調整 Z 幣獲取規則的權利
5. 帳號停用時，未使用的 Z 幣不予退還

→ 這樣就完全避開了虛擬貨幣的法規問題
```
