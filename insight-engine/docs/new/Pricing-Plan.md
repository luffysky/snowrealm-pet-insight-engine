## 一、C 端定價（雪凜 Pro）

### 1.1 方案總覽

| 方案 | 月費 | 年費 | 終身 | 說明 |

### 1.3 定價心理學設計

```
Free → Pro 的轉換動力：
  - 聊天次數用完（高頻用戶 3 天就會到上限）
  - 看到好的邊框/服裝被鎖住
  - 深夜發現聊天沒了，恰好是情感依賴時刻
  
Pro → Pro+ 的升級動力：
  - Premium AI 明顯比 Standard 聰明
  - 5 次/天不夠用（重度用戶）
  - TTS 語音的情感體驗差異很大

定價錨點：
  月費 NT$149 ≈ 2 杯手搖飲
  年費 NT$1,188 ≈ 每月 99 → 讓人覺得很划算
```

## 三、一次性終身方案（LTD）

### 3.1 C 端終身策略

```
限量策略（不是永久開放）：
  - 第一批：500 名創辦人特別席
  - 售完就結束，不再補充
  - 目的：早期現金流 + 核心用戶培育
```

| LTD 方案 | 價格 | 相當於 | 備註 |
|---------|------|------|------|
| Pro 終身 | NT$3,980 | ~26 個月月費 | 限前 500 名 |
| Pro+ 終身 | NT$6,980 | ~23 個月月費 | 限前 200 名 |

**為什麼 LTD 不是永久開放：**
- 創辦人價格特殊，象徵早期支持
- 避免長期影響訂閱收入
- 稀缺性創造緊迫感
- 20-26 個月後開始回本，低風險

**訂閱 vs LTD 損益平衡：**
```
Pro 月費 NT$149：
  LTD NT$3,980 ÷ NT$149 = 26.7 個月 ≈ 2.2 年回本
  
Pro+ 月費 NT$299：
  LTD NT$6,980 ÷ NT$299 = 23.3 個月 ≈ 1.9 年回本
```

### 3.2 B 端終身（不建議）

B 端客戶服務成本高（客製化、支援、DB storage）、客戶有企業價值，不適合 LTD。
如要吸引長期客戶，改用「預付年費 9 折」策略即可。

## 四、Z 幣與訂閱的關係

```
Pro 訂閱 ≠ 取代 Z 幣

訂閱解鎖「上限」，Z 幣決定「用多少」：
  - Free：每日賺取 Z 幣，可買基本消耗品
  - Pro：+ 每月 200 Z 幣配額 + 上限解鎖
  - Pro+：+ 每月 500 Z 幣配額 + 所有商城可購

Pro 用戶仍然參與 Z 幣經濟，只是：
  1. 有更多 Z 幣來源（月配額）
  2. 商城有更多選項（Pro 限定商品）
  3. Z 幣儲值的 bonus 更高（Pro 首儲 +70%，一般 +50%）
```

## 五、推薦機制

```
推薦計畫：
  - 你推薦朋友加入 → 雙方各得 100 Z 幣
  - 朋友升級 Pro → 你再得 200 Z 幣
  - 推薦 5 人升級 → 你獲得一個月 Pro 免費
  - 推薦 20 人升級 → 終身 Pro

Pro 用戶推薦碼顯示在帳號頁面，方便分享。
```

## 六、推出時間表

```
現在（無用戶期）：
  ✅ 後台定價頁面建好（/pricing）
  ✅ Free 方案完整可用
  ⏳ Pro/Pro+ 方案顯示「即將推出」+ Waitlist

有 100 用戶後：
  - 開放 LTD 創辦人席（限 500/200 名）
  - 推廣碼系統上線
  - Stripe/藍新金流整合

有 1,000 用戶後：
  - 正式月費/年費開放
  - B 端 Waitlist 開放
  - 企業方案洽談頁面

有 5,000 用戶後：
  - B 端正式推出
  - LTD 結束（限量已售完或時間到期）
```
