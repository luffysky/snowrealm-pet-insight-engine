## Bug 1：「已經填過問卷」偵測錯誤 ★ 最緊急

現在填過任何一份問卷，所有問卷都會顯示「你似乎已經填過了」。
原因：progress API 只查 fingerprint，沒有加 survey_id。

```
🔧 src/app/api/surveys/progress/route.ts

第 43 行：
  舊：SELECT id, status FROM responses WHERE fingerprint = $1 AND status = 'completed' LIMIT 1
  新：先查 survey_id，再加條件

改成：
  // 先查 survey_id
  const survey = await queryOne<{ id: string; tenant_id: string }>(
    'SELECT id, tenant_id FROM surveys WHERE slug = $1', [surveySlug]
  )

  // 檢查是否已提交過「這份問卷」
  const existing = await queryOne<{ id: string; status: string }>(
    'SELECT id, status FROM responses WHERE fingerprint = $1 AND survey_id = $2 AND status = $3 LIMIT 1',
    [fingerprint, survey?.id, 'completed']
  )

注意：survey 查詢要移到 existing 查詢之前（把原本第 56-59 行的 survey 查詢提前到第 42 行）。
```

📄 src/lib/adEngine.ts

export const AD_DAILY_LIMIT = 10

export async function canWatchAd(userId: string): Promise<boolean> {
  // 查今日已看廣告次數
  const result = await queryOne<{ count: string }>(
    `SELECT COUNT(*) as count FROM daily_task_logs
     WHERE user_id = $1 AND task_id = 'watch_ad'
     AND completed_at >= DATE_TRUNC('day', NOW() AT TIME ZONE 'Asia/Taipei') AT TIME ZONE 'Asia/Taipei'`,
    [userId]
  )
  return parseInt(result?.count ?? '0', 10) < AD_DAILY_LIMIT
}

export async function recordAdWatch(userId: string): Promise<{ earned: number }> {
  // 呼叫 dailyTaskEngine 的 completeTask
  const result = await completeTask(userId, 'watch_ad')
  return { earned: result.earned }
}
