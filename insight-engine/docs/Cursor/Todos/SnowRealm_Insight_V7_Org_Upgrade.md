# 👥 一、多人「共同回答」模式（NEW）

## 🔥 定義
不是多人編輯問卷  
而是：

👉 多人一起回答「同一份問卷」（組織內部）

---

## 🧩 使用場景

- 團隊回饋
- 部門評估
- 內部氣氛調查
- 專案 retrospection

---

## 🧠 模式設計

### 1️⃣ 匿名模式（預設）
- 不記名
- 更真實

### 2️⃣ 記名模式
- 顯示回答者
- 用於績效 / review

---

## 🗂 DB 設計

table: org_surveys
- id
- org_id
- is_anonymous (bool)

table: org_responses
- id
- survey_id
- user_id (nullable)
- answers
