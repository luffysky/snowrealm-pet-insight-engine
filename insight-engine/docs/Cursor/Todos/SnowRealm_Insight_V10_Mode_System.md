# SnowRealm Insight V10 — AI 模式系統 + UI / 轉換設計

---

# 🎯 核心定位
將 AI 問卷生成升級為「模式系統」
每個模式 = 不同人格 + UI + 轉換策略

---

# 🧠 一、AI 模式系統架構

## Prompt 結構

Final Prompt =
System Base Prompt  
+ Style Prompt  
+ User Topic  
+ Safety Layer  

---

## 🔒 Safety Layer（全模式共用）

- 禁止羞辱、攻擊性語言
- 避免極端負面誘導
- 保持「刺但不傷人」

---

## 📦 輸出格式（固定）

```json
{
  "title": "",
  "description": "",
  "questions": [
    {
      "id": 1,
      "text": "",
      "type": "text"
    }
  ]
}
```
