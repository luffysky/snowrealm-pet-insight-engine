## P0：立刻執行（Bug + DB Schema）

### SQL-1：新增 DB 欄位與表格
先跑這段 SQL，後續所有功能才能執行：

```sql
-- 封面圖片
ALTER TABLE surveys ADD COLUMN IF NOT EXISTS cover_image_url TEXT;

-- 密碼鎖
ALTER TABLE surveys ADD COLUMN IF NOT EXISTS access_password TEXT;

-- 簽到任務記錄（若尚未建立）
CREATE TABLE IF NOT EXISTS daily_task_logs (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL,
  task_id TEXT NOT NULL,
  completed_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE INDEX IF NOT EXISTS idx_daily_tasks_user_date ON daily_task_logs (user_id, completed_at);

-- Prompt 分享
CREATE TABLE IF NOT EXISTS shared_prompts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID,
  prompt_text TEXT NOT NULL,
  survey_title TEXT,
  category TEXT DEFAULT 'general',
  likes INT DEFAULT 0,
  is_public BOOLEAN DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### BUG-1：填過問卷偵測錯誤（最緊急）

**問題**：填過任何一份問卷後，所有問卷都顯示「你似乎已經填過了」。
**根因**：`progress/route.ts` 只用 fingerprint 查，沒有加 `survey_id` 條件。

**修改檔案**：`src/app/api/surveys/progress/route.ts`

```
修改方式：
  先查 survey 取得 id，然後在 existing 查詢加上：
    AND survey_id = $2
```

---

### BUG-2：AiSurveyChat 按 Enter 視窗跳動

**問題**：每次訊息更新都觸發 scrollIntoView，造成畫面跳動。

**修改檔案**：`src/components/admin/AiSurveyChat.tsx`

```
修改方式：
  加 chatContainerRef，useEffect 裡改為：
    只在 scrollTop + clientHeight + 100 >= scrollHeight 時才觸發 scrollIntoView
  對話容器加 ref={chatContainerRef}
```

## P1：核心 AI 體驗

### TASK-3a：AI Prompt 強制生成 resultConfig + 選項 Emoji

**修改檔案**：`src/lib/aiSurveyPrompt.ts`

```
system prompt 新增兩段要求：

1. 選項 emoji（全題型）：
   每個選項的 options 陣列格式改為包含 emoji 欄位：
   { "label": "主動跟大家聊天", "value": "主動跟大家聊天", "emoji": "💬" }
   emoji 要直覺好辨識，不重複使用同一個。

2. resultConfig（測驗型問卷必須生成）：
   判斷標準：問卷目的是讓填答者得到「你是什麼類型」就必須生成。
   格式：
   {
     "scoringRules": {
       "q1": { "選項A value": "typeKey1", "選項B value": "typeKey2" }, ...
     },
     "resultTypes": [
       {
         "key": "typeKey1",
         "name": "毒舌系真心話王",   ← 格式：X系+Y者/王/家，6-10字
         "emoji": "😈",
         "description": "2-3 句描述，讓人覺得被看穿",
         "traits": ["直接", "真誠", "不怕得罪人"]
       },
       ... 至少 4-6 個結果
     ]
   }

AiGeneratedSurvey interface 新增 resultConfig 欄位
parseSurveyJson() 解析時加上 resultConfig 欄位
```

**修改檔案**：`src/components/admin/AiSurveyChat.tsx`

```
createSurveyFromAi() 的 patchBody 加：
  if (data.resultConfig) patchBody.result_config = data.resultConfig

建立題目時帶 emoji：
  options: q.options?.map(opt => ({ label: opt.label, value: opt.value, emoji: opt.emoji || '' })) ?? []
```

**修改檔案**：`src/components/survey/QuestionSingle.tsx` + `QuestionMultiple.tsx`

```
選項顯示改為優先用 option.emoji，fallback 到 getOptionEmoji(option.value)：
  const emoji = option.emoji || getOptionEmoji(option.value)
```

**修改檔案**：`src/types/survey.ts`

```
QuestionOption 確認有：emoji?: string
```
