## 一、「其他」選項開放文字填答

使用者選了「其他」時，自動出現文字輸入框讓他填寫具體內容。
答案格式：`"其他:使用者輸入的內容"`

### DB

```sql
🗄️ ALTER TABLE questions ADD COLUMN IF NOT EXISTS allow_other_text BOOLEAN DEFAULT false;
```

### 修改

```
🔧 src/types/survey.ts
   Question interface 新增：
     allowOtherText?: boolean

🔧 src/components/survey/QuestionSingle.tsx
   - 偵測選中的 value 是否包含「其他」（或 option 有 isOther 標記）
   - 選中時在選項下方顯示文字輸入框
   - 答案存成 "其他:使用者輸入的文字"
   - 如果沒輸入文字就只存 "其他"

🔧 src/components/survey/QuestionMultiple.tsx
   - 同 QuestionSingle 邏輯
   - 多選時「其他」被勾選 → 顯示輸入框
   - 答案陣列裡的「其他」項替換成 "其他:文字"

🔧 src/app/(admin)/insight-admin/surveys/page.tsx
   - 題目建立/編輯表單新增勾選框：「☐ 允許『其他』文字輸入」
   - 勾選後，選項裡需要有一個 value 包含「其他」的選項

🔧 src/lib/surveyRepo.ts
   - toQuestion() 新增 allowOtherText 欄位映射
   - createQuestion / updateQuestion 支援 allow_other_text

🔧 src/app/api/admin/surveys/[id]/questions/route.ts
   - POST/PATCH 接受 allowOtherText 參數
```
