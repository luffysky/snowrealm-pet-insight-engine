## 第三部分：成長引擎（Phase 2）

> 核心思路：**問卷不只是工具，是可被分享的娛樂內容**。
> B 端引擎賺錢，C 端引擎帶流量，兩個同時轉才會飛。

### 🔵 10. 雙引擎定位

```
B 端引擎（現有）：
  商家建問卷 → 收回覆 → AI 洞察 → LINE 推播 → 營收

C 端引擎（需要補）：
  填答者覺得好玩 → 分享結果 → 朋友來填 → 免費流量 → 數據飛輪
```

C 端引擎的關鍵是讓問卷結果「值得分享」。

### 🔵 11. 爆款問卷模板（C 端傳播用）

```
🗄️ DB：新增到 survey_templates，industry = 'viral'

10 個模板（每個 8-12 題，3 分鐘填完）：
  1.「你在朋友眼中是什麼人？」— 人格測驗（守護者/冒險家/智者...）
  2.「你的戀愛人格」— 心理測驗，結果帶情緒共鳴
  3.「你是哪種動物？」— 輕鬆娛樂（金毛/貓頭鷹/水獺...）
  4.「朋友對你的真實印象」— 匿名回饋，分享給朋友填
  5.「你的未來人生路線」— 預測型，結果帶故事性
  6.「你在職場的角色」— 專業但有趣（領導者/創意家/執行者...）
  7.「情侶默契測驗」— 雙人互動，比較兩人答案
  8.「你的人生價值觀」— 深度型，結果有洞察
  9.「你的隱藏天賦」— 探索型，結果帶驚喜
  10.「朋友適合你的程度」— 關係測驗，正向包裝

每個模板需要：
  - 完整題目 + 選項
  - 結果邏輯（答案組合 → 角色/類型）
  - 結果頁文案（角色名 + 描述 + 建議）
  - Story Card 客製配色
```

### 🔵 13. Z 幣系統

```
🗄️ DB：
  CREATE TABLE zcoin_wallets (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID, line_user_id TEXT,
    balance INT DEFAULT 0, total_earned INT DEFAULT 0, total_spent INT DEFAULT 0,
    created_at TIMESTAMPTZ DEFAULT NOW()
  );
  CREATE TABLE zcoin_transactions (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    wallet_id UUID REFERENCES zcoin_wallets(id),
    amount INT NOT NULL, type TEXT NOT NULL, reason TEXT NOT NULL, reference_id TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
  );

取得：填問卷 +1 / 分享 +5 / 邀請 +10 / 連續登入 +2 / 問卷被 100 人填 +50
```
